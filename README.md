# Танковый завод — ЛР1, вариант 19

Пошаговая головоломка на Pygame: дрон перемещается по сетке 10 x 10, подбирает шасси, башню и орудие и доставляет их на сборочную платформу в строгом порядке. Все три детали начинают на отдельных конвейерных дорожках и по мере ходов перевозятся в зоны ожидания вокруг платформы: орудие — к (6, 8), шасси — к (7, 8), башня — к (8, 7). После каждого успешного действия свободные детали на лентах одновременно сдвигаются на одну клетку, а HUD показывает их координаты и число перемещённых деталей.

![Игровое поле «Танковый завод»](screenshots/factory_gameplay.png)

## Запуск

Требуется Python 3.12 или новее.

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Управление

- Стрелки — переместить дрон ровно на одну клетку.
- `Пробел` — взять деталь, положить её на пол или установить на сборочную платформу.
- `R` — начать текущую сессию заново.
- `M` — вернуться в меню.
- `Esc` — закрыть игру.
- В меню `Enter` или `Пробел` — начать игру.

Дрон переносит только одну деталь. Для сборки нужно установить детали на платформу в порядке: шасси (индекс 0), башня (индекс 1), орудие (индекс 2). При неверном порядке деталь остаётся у дрона, а стек сборки не меняется. Стены и границы блокируют движение дрона; столкновение деталей на конвейере не удаляет и не перезаписывает объекты.

## Спрайты из Aseprite

Экспортируй изображения как отдельные PNG размером 16 x 16 пикселей и клади их в `assets/`. Фон лучше оставить прозрачным. Игра подхватит файлы при следующем запуске; если файл отсутствует, для этого объекта останется встроенная отрисовка.

- Детали: `chassis.png`, `turret.png`, `cannon.png`.
- Дрон: `drone.png`.
- Поле: `floor.png`, `wall.png`, `assembly.png`.
- Конвейеры по направлениям: `conveyor_up.png`, `conveyor_right.png`, `conveyor_down.png`, `conveyor_left.png`.

Спрайты масштабируются без сглаживания целыми множителями, чтобы сохранять пиксельный рисунок. Картинки для конвейера должны уже содержать стрелку нужного направления.

## Проверка логики

Тесты используют только стандартный `unittest` и не требуют запуска окна Pygame:

```powershell
python -m unittest discover -s tests -v
```

## Реализованные критерии ЛР1

- Окно Pygame, игровой цикл и поле 10 x 10.
- Координаты дрона, деталей и лент задаются целыми `grid_x`, `grid_y`.
- Один ввод стрелкой перемещает дрон на одну клетку; повтор клавиши при удержании игнорируется.
- Конвейеры сдвигают свободные детали по вектору на одну клетку за ход.
- Сборочный стек проверяется по индексам `[0, 1, 2]`; интерфейс показывает порядок и прогресс.
- Есть стартовый экран, HUD и экран успешной сборки.
